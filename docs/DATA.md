# Dataset Format

The public code expects one design CSV and one VTU file per operating scenario.

## Design CSV

Required columns:

```text
Scenario,
Rack1Power,Rack2Power,Rack3Power,Rack4Power,Rack5Power,
Rack6Power,Rack7Power,Rack8Power,Rack9Power,Rack10Power,
CRAC1_Temp,CRAC2_Temp,
CRAC1_Fan,CRAC2_Fan
```

The paper experiments used:

- rack heat load: 1.0-8.0 kW;
- CRAC supply temperature: 18.0-22.0 degC;
- CRAC fan-speed ratio: 70-100%.

OOD experiments can be generated by expanding these ranges, but such ranges should be clearly reported because they change the evaluation distribution.

## CFD Directory

The default layout is:

```text
data/<Scenario>/VTM/region_0.vtu
```

Each VTU file must contain:

- cell centers with identical mesh topology across scenarios;
- `Temperature (C)` in cell data;
- `Velocity (m/s)` in cell data.

The velocity field is used as privileged training information for the PDE residual. It is not an inference-time input to HMNO.

## Processed Files

`scripts/preprocess.py` writes:

```text
data_processed/
├── coords.npy
├── design_params.npy
├── scenario_ids.npy
├── norm_stats.json
├── split_scenarios.json
├── val_indices.npy
└── fields/
    ├── scenario_0001.npz
    └── ...
```

Each `scenario_XXXX.npz` contains:

- `temp`: normalized temperature field;
- `vel`: normalized velocity field.
